# Лабораторная работа № 3

Тема: методы, массивы и алгоритмы сортировки в C#.

## Задание

Разработать консольное приложение с меню, игрой «Отгадай ответ»
и выводом информации об авторе. Реализовать гномью сортировку
и сортировку перемешиванием, сравнить время их выполнения.

## Возможности программы

1. **Отгадай ответ** — вычисление значения функции по введённым
   углам альфа и бета. Пользователю даётся три попытки.
   Ответы сравниваются после округления до двух знаков после запятой.
2. **Об авторе** — вывод ФИО и учебной группы.
3. **Сортировка массива** — создание массива со случайными
   целыми числами от −100 до 100 включительно, сортировка
   двумя способами и измерение времени каждого алгоритма.
4. **Выход** — завершение программы с подтверждением.

Формула для игры:

`f = sin²(3π/4 + α/3) + √cos(β)`

Углы вводятся в градусах. Косинус угла бета должен быть
неотрицательным.

Массивы сортируются по возрастанию. При длине массива
более 10 элементы не выводятся, но сортировка выполняется.

## Как запустить

1. Установить .NET SDK, совместимый с версией,
   указанной в файле проекта .csproj.
2. Скачать и распаковать проект.
3. Открыть терминал в папке, где находится ConsoleApp1.sln.
4. Выполнить команду:

```bash
dotnet run --project ConsoleApp1
```

5. Выбрать пункт меню, введя число от 1 до 4.

## Пример работы

Выбираем пункт 1 — «Отгадай ответ».
Вводим угол альфа 135°, угол бета 0° и ответ 1.

Ввод пользователя по порядку:

```text
1
135
0
1
```

Программа выводит:

```text
Поздравляем! Вы выиграли!
```

После завершения игры снова отображается главное меню.
